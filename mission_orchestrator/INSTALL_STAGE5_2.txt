Stage 5.2 installation / validation
===================================

1. Replace the working tree with this package or apply the listed Stage-5.2 files.
2. The Pentest repository upgrades automatically from migration 8 to migration 9 on first Stage-5.2 startup.
3. Start the Global Mission Orchestrator as usual on http://127.0.0.1:8780.
4. Start the Pentest Subsystem:

   cd D:\mission_orchestrator
   python run\pentest_subsystem.py --host 127.0.0.1 --port 8790

5. In another PowerShell:

   cd D:\mission_orchestrator
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
   .\STAGE5_2_ACCEPTANCE.ps1

Expected active Pentest control:
  stage5.2-reconnaissance-agent

Expected Pentest migration:
  9

Expected canonical inventory:
  1847 tests

Important authority boundary:
  Stage 5.2 processes imported reconnaissance observations and publishes governed
  discovery action proposals. It does NOT directly invoke scanners/tools, open target
  network connections, actuate targets, or mint PolicyDecision authorization.
  Controlled execution remains Stage 6 authority.
