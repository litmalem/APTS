Stage 3.2.5 installation
========================

Baseline required: Stage 3.2.4 — Planning and Run Activation (accepted v2 harness)

1. Stop Mission Orchestrator.
2. Back up the Mission Orchestrator database.
3. Extract STAGE3_2_5_WAITING_DEPENDENCY_CONTROL_PATCH.zip directly into D:\mission_orchestrator with overwrite enabled.
4. Do NOT create migration 009. Repository migration level remains 8.
5. Run:

   cd D:\mission_orchestrator
   python -m compileall -q mission_orchestrator tests
   python -m pytest -q

   Expected: 182 passed

6. Start Mission Orchestrator and verify /health reports:

   control_version = stage3.2.5-waiting-dependency-control
