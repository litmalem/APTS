Stage 5.5 installation / validation
===================================

1. Replace the working tree with this package or apply the files listed in PATCH_FILE_LIST_STAGE5_5.txt.
2. The Pentest repository upgrades automatically from migration 11 to migration 12 on first Stage-5.5 startup.
3. Start the Global Mission Orchestrator as usual on http://127.0.0.1:8780.
4. Start the Pentest Subsystem:

   cd D:\mission_orchestrator
   python run\pentest_subsystem.py --host 127.0.0.1 --port 8790

5. In another PowerShell:

   cd D:\mission_orchestrator
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
   .\STAGE5_5_ACCEPTANCE.ps1

Expected active Pentest control:
  stage5.5-attack-path-planning-agent

  12

  1929 tests

Important authority boundary:
  Stage 5.5 consumes the exact authoritative Stage-5.4 Vulnerability Hypothesis output/evidence,
  builds evidence-bound candidate attack-path graphs, ranks candidate paths for validation priority,
  and records path provenance. Candidate paths are conditional planning hypotheses, not proof of
  reachability or exploit success. The planner does NOT execute validation, create confirmed findings,
  create execution requests, invoke target tools, open target-network connections, actuate targets,
  or mint PolicyDecision authorization. Controlled execution remains Stage 6 authority.
