Rollback
--------
Application rollback requires restoring the pre-Stage-3.5.1 source tree and repository
backup as one consistent unit. Migration 027 creates a new durable table and should not
be casually downgraded by application-code rollback alone. Use the deployment's tested
schema rollback/recovery procedure.
