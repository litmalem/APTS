  1. Stop the Mission Orchestrator process using port 8780.

  5. Start Mission Orchestrator on port 8780.

  6. Verify runtime activation:

       Invoke-RestMethod http://127.0.0.1:8780/health |

       cd D:\mission_orchestrator
