IMPORTANT
---------
Stage 3.6.10 is a closure/acceptance gate. It adds no outcome-processing
primitive, no task/Mission completion authority, no Governance query, no
runtime I/O, no dispatch/redelivery, no target actuation, no new lifecycle
transition path, and no new persistence capability.

The runtime does NOT self-certify acceptance. Official Stage-3.6 closure is
the result of the external acceptance harness on the target host.

INSTALL / UPDATE
----------------
1. Stop the currently running Mission Orchestrator process on port 8780.

2. Back up D:\mission_orchestrator. Preserve local runtime data, databases,
   secrets/configuration, and any operator-managed files before replacement.

3. Apply/extract this Stage-3.6.10 package over D:\mission_orchestrator.

4. Verify that migration 045 was NOT introduced:

   Get-ChildItem D:\mission_orchestrator\migrations\*.sql |
       Sort-Object Name |
       Select-Object -Last 3 Name

   The newest migration must remain:

   044_stage3_6_9_outcome_lineage_replay_recovery.sql

5. Start/restart Mission Orchestrator with the existing launcher.

6. Verify activation:

   Invoke-RestMethod http://127.0.0.1:8780/health |
       Select-Object `
           status,
           control_version,
           mission_repository_migration_level,
           stage3_6_outcome_acceptance_gate_schema_version,
           stage3_6_outcome_acceptance_gate_baseline,
           stage3_6_outcome_acceptance_gate_declared_only,
           stage3_6_outcome_acceptance_gate_runtime_self_certification,
           stage3_6_outcome_acceptance_gate_external_execution_required

   Expected essentials:

   status                                             ok
   control_version                                    stage3.6.10-outcome-acceptance-regression-gate
   mission_repository_migration_level                 44
   stage3_6_outcome_acceptance_gate_schema_version   apts-mission-stage3.6-outcome-acceptance-gate-v1
   stage3_6_outcome_acceptance_gate_baseline         STAGE_3_6_1_THROUGH_3_6_9

   cd D:\mission_orchestrator

--------
If activation or acceptance fails:

1. Stop Mission Orchestrator.
2. Restore the backed-up Stage-3.6.9 source tree.
3. Do NOT perform a database downgrade. Stage 3.6.10 introduced no migration,
   so repository migration level remains 44.
4. Restart the Stage-3.6.9 runtime and verify its health/control version.
