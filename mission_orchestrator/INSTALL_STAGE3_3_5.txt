  D:\mission_orchestrator

1. Stop Mission Orchestrator before replacing files.
2. Back up the repository and database.
3. Extract the Stage-3.3.5 patch over D:\mission_orchestrator preserving paths.
4. Apply database migration 013 if the production database is external/manual-migration managed:

     stage3.3.5-planner-invocation-plan-generation
