Operational semantics:
- Stage 3.6.8 accepts only an exact, current Stage-3.6.7 READY decision with zero blockers.
- It revalidates the bound Stage-3.6.6 success-criteria evaluation and Stage-3.6.5 all-task terminal/verified-complete aggregation.
- The immutable mdecl-* declaration is persisted before lifecycle handoff.
- Mission state changes are performed only through the canonical Stage-3.2 lifecycle command path: RUNNING -> CLEANING_UP -> COMPLETED.
- Direct state-transition bypass, Governance/runtime queries, dispatch, external network I/O, and target actuation are forbidden in Stage 3.6.8.
- Replaying the same idempotency key after a partial process crash resumes the durable handoff from RUNNING, CLEANING_UP, or COMPLETED without creating a second declaration.

Do not replace or delete the live data directory from the bundle.
