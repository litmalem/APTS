adaptation/replanning authority, Governance/runtime I/O path, Plan mutation,

the result of the external acceptance harness on the target host.

INSTALL / UPDATE
----------------
1. Stop the currently running Mission Orchestrator process on port 8780.

2. Back up D:\mission_orchestrator. Preserve local runtime data, databases,
   secrets/configuration, and operator-managed files before replacement.

3. Overlay/extract the Stage-3.7.10 patch contents onto D:\mission_orchestrator.

4. Do NOT apply a new database migration. Verify that the newest migration is
   still:

   053_stage3_7_9_adapt_replan_lineage_replay_recovery.sql

   Example:

   Get-ChildItem D:\mission_orchestrator\migrations\*.sql |
       Sort-Object Name |
       Select-Object -Last 3 Name

5. Start/restart Mission Orchestrator with the existing launcher.

6. Verify activation:

   Invoke-RestMethod http://127.0.0.1:8780/health |
       Select-Object `

           stage3_7_adapt_replan_acceptance_gate_baseline,

           stage3_7_adapt_replan_acceptance_gate_external_execution_required
